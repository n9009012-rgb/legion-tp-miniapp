# LEGION TP Mini App 1.0

Первая визуальная версия мобильного приложения LEGION TP.

В этой версии:
- фирменный дизайн LEGION;
- Главный экран;
- Начать работу;
- Завершить работу;
- Сканер QR;
- Мой отчёт;
- Продажи;
- Уведомления.

Пока это UI-прототип. На следующем этапе подключаем реальные функции существующего Legion TP Control Bot и общую базу.

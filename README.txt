# LEGION TP Mini App — FULL 1.0

Основано на текущем Legion TP Bot из предоставленного архива.

## Что уже подготовлено
- современный интерфейс LEGION TP;
- Telegram Mini App;
- кнопки Начать/Завершить;
- передача геолокации в бот;
- Заказы и Бутылки;
- Мой отчёт;
- QR;
- единая кнопка Mini App в обычном меню бота.

## Важное ограничение
GitHub Pages — статический хостинг. Он не может напрямую читать локальный `data/bot.db` на компьютере, где запущен бот.
Поэтому Mini App отправляет действия через Telegram в существующий бот. Для фото начало/конец бот после получения геолокации просит прислать фото в чат. Это сделано намеренно, чтобы не передавать секреты и не открывать локальную базу наружу.

Для полностью бесшовной передачи фото и отображения данных прямо внутри Mini App нужен отдельный публичный HTTPS API-сервер. Его можно добавить следующим этапом без изменения базы данных.

## Установка интеграции
Скопировать:
- `miniapp/index.html` и `miniapp/legion-logo.png` в GitHub Pages;
- `handlers/miniapp.py`, обновленные `bot.py`, `config.py`, `keyboards.py` — в проект бота.

Сохранить `.env` и существующую `data/bot.db`.

После замены:
`pip install -r requirements.txt`
`python bot.py`
